# Working_W_Claude
## PentAnalyst

- `index.html` — 단일 파일 프론트엔드 (브라우저에서 바로 열기 가능)
- `worker/` — Yahoo Finance용 자체 프록시 (Cloudflare Worker). 배포 방법은 `worker/README.md` 참고.
  배포 후 `index.html` 우측 상단 **API 키 & 구글 검색 설정**에 Worker 주소를 입력하세요.
  (Worker 코드가 바뀌면 대시보드에서 코드를 다시 붙여 넣고 **Deploy** 해야 새 기능이 동작합니다.)

### 주요 기능

- **회사명/티커 검색** — `tesla`, `basf`, `samsung`, `삼성전자`처럼 이름으로도 검색(Yahoo 검색, 전 세계 거래소). 입력 중 자동완성 목록이 뜨고, 미국 외 종목은 현지 통화로 표시됩니다.
- **검색 기록** — 검색한 종목이 검색창 옆에 쌓입니다(이 브라우저에만 저장). 클릭하면 최신 데이터로 다시 분석합니다.
- **프로 차트** — TradingView 스타일: 휠/핀치 확대·축소, 드래그 이동, 가격·날짜축 스케일, 크로스헤어, 로그 스케일, 일/주/월봉, 6가지 차트 유형(캔들·속 빈 캔들·하이킨아시·OHLC·라인·영역), 전체화면, PNG 저장.
- **분석 도구 27종** — 이동평균, 볼린저, 켈트너, 돈치안, 일목균형표, 파라볼릭 SAR, 슈퍼트렌드, 지그재그, 선형회귀 채널, 자동 지지/저항, 캔들 패턴 + RSI, MACD, 스토캐스틱, CCI, 윌리엄스 %R, ATR, ADX/DMI, OBV, MFI, CMF, ROC, 포스인덱스, 볼린저 %B/밴드폭, 거래량. 하단 패널은 여러 개를 동시에 쌓을 수 있고 파라미터·색상을 바꿀 수 있습니다.
- **그리기 도구** — 추세선, 연장선, 수평/수직선, 평행 채널, 사각형, 피보나치 되돌림, 측정, 앵커드 VWAP. 자석(OHLC 스냅), 선택·이동·삭제(Delete), 종목별 자동 저장.
- **스윙 트레이딩 프리셋 5종 (클릭 한 번)** — Al Brooks 프라이스 액션(20 EMA·H2/L2·측정 이동), 불단왕 4강 지표(이평선 7·25·50·100·200 + VWMA100 + VPVR), 터틀 돈치안 돌파, 엘더 트리플 스크린, 일목균형표 삼역호전. 지표 구성·신호 마커·현재 상태 판단·"이 종목에서의 과거 신호 성과"를 보여줍니다.
  - 이 프리셋은 널리 알려진 기법의 **공개된 규칙을 코드로 옮긴 것**이며, 수익을 보장하는 '인증된 전략'이 아닙니다. 성과 요약은 불러온 구간에 대한 단순 시뮬레이션(수수료·슬리피지·세금 미반영)입니다.
- **심층 분석 / AI 분석** — Yahoo 실적·재무·애널리스트·수급·뉴스 데이터, 버튼을 눌렀을 때만 Gemini 호출. **무료 Gemini 키로 동작**합니다(구글 검색 Grounding은 유료라 설정에서 켜기 전까지 꺼져 있으며, AI는 앱이 가져온 검증 데이터만 근거로 분석). 호출량이 무료 한도를 넘으면 오류 메시지가 표시됩니다. **키를 두 개** 넣을 수 있습니다: 무료 키는 모든 AI 기능에, 유료 키는 검색 Grounding 호출(AI 분석 버튼·전문가 채팅)에만 쓰이며(설정에서 Grounding을 켠 경우), 유료 키가 막히면 무료 키로 검색 없이 다시 시도합니다.
- **관심종목 탭 (모니터링)** — 분석 화면·스크리너의 ★ 버튼이나 탭의 검색창으로 종목을 저장(이 브라우저에만, 최대 120개). 표/카드 보기, 그룹, 정렬·필터, 3개월 스파크라인, **신호 칩**(Minervini 템플릿·피벗 돌파·RS 블루닷·TTM 스퀴즈·눌림목·추세 강함·일목·신고가 근접·과열·추세 이탈·거래량 급증), 거래량 배수·52주 위치·매수목표 괴리. 종목별 메모(매수 근거·반증 조건)·매수/손절/목표가·수량·알림(가격·등락·거래량·신고가·50일선·RSI, 엣지 트리거+쿨다운), 다음 실적일, '마지막 접속 이후 변화' 요약, 리스크 점검(섹터 쏠림·오픈 리스크·ATR% 급등·상관), JSON 내보내기/가져오기. 시세는 탭을 열어 둔 동안만 갱신되며(**앱을 닫으면 알림이 오지 않음**) 일봉은 하루 단위 캐시로 무료 한도를 아낍니다. 관심종목이 있으면 앱이 이 화면에서 시작합니다.
- **밸류에이션 계산기(내 가정)** — 분석 탭의 카드: 목표 P/E 기반 적정가·안전마진, 현재 주가가 내포한 FCF 성장률(역방향 DCF), 약세/기준/강세 3시나리오, 애널리스트 목표가·52주 범위 바. 앱이 미래 숫자를 채워 넣지 않고 입력한 가정으로만 계산합니다(FCF의 통화가 불확실하면 확인 체크 후 계산).
- **기술적 분석 향상** — 새 분석도구 8종(TTM 스퀴즈, 스토캐스틱 RSI, 아룬, TRIX, 피벗 포인트, RS 라인 vs SPY, 엘더 임펄스, BandWidth 125봉 최저), 터틀(상태 판정 버그 수정·S1 skip·S2·피라미딩), Minervini(8조건·RS 근사·가용 구간 표기), Brooks(신호봉 품질·두 다리 눌림·A/B/C 등급·롱/숏 분리), 일목(상태/이벤트 분리·구름 두께), 엘더(임펄스·buy-stop). 프리셋 패널에 표본 수 경고와 '이 분석의 한계' 안내가 붙습니다.
- **AI 분석 자동 실행** — 종목을 검색하면 데이터가 뜬 직후 AI 분석(종목 분석·불단왕·전일 복기)이 이어서 자동으로 채워집니다(설정에서 끌 수 있음). 무료 키로만 호출하며, 유료 키로 검색 Grounding을 켠 경우 종목 분석 탭은 과금 방지를 위해 자동 실행하지 않고 버튼으로만 실행합니다. 기본 모델은 `gemini-3.5-flash-lite`(설정에서 변경 가능).
- **5인 난상토론 (채팅형)** — '5인 합동 토론'을 고르고 질문하면 데이비드·빅터·클라라·마커스·소피아가 서로의 말을 받아 반박·보완하는 채팅이 차례로(입력 중… → 말풍선) 펼쳐집니다. 중간에 내가 끼어들 수 있고 '토론 이어가기'로 다음 라운드를 봅니다. AI 호출 1회로 토론 대본 전체를 받아 재생하는 방식이라 무료 키로도 쓸 수 있으며, 근거 수치는 앱의 검증 데이터만 쓰도록 지시합니다(AI가 쓴 대본이며 투자 권유가 아님).
- **스마트 스크리너 (Finviz 방식)** — 미국 주요 종목 ~340개를 실시간 값으로 필터링. 기본정보/재무/기술 3개 탭에 50개 필터, 보기(개요·밸류에이션·재무·기술) 전환, 퀄리티·가치·모멘텀 점수 정렬, 원클릭 프리셋 12개(장기 투자·스윙·이벤트), **내 필터를 프리셋으로 저장**(이 브라우저에 보관).
- **분봉 차트** — 1·5·15·30·60분봉(Yahoo 제공 범위: 1분봉 최근 7일, 5~30분봉 약 60일), 세션 VWAP, 전일 고저종선, Brooks 5분봉 뷰 프리셋.
- **전일 복기 탭** — 직전 정규장 세션을 5분봉으로 복기: 일간 요약, Brooks식 날 유형 분류, 세션 차트, 봉별 해설(심리 해석은 가격 흐름에서 추정한 것), 같은 날 시장(SPY·QQQ·IWM·VIX) 비교. AI 해설은 버튼을 눌렀을 때만.
- **환율 탭** — 주요 통화쌍 보드(달러·유로·원·엔 등), 전용 차트, 통화 강세 미터·교차환율, 금리·달러지수 등 환율 변수, 환율 ETF·해외주식 환율 효과 계산기.
- **시장 · 매크로 탭** — 시가총액 히트맵(트리맵), 산업·테마 순위와 주요 종목, 섹터 로테이션, 금리·원자재·글로벌 지표, 시장 폭과 위험선호 점수.
- 위 세 탭은 Worker의 `/api/spark`, `/api/quotes`와 분봉 차트를 사용하므로 **Worker를 다시 배포**해야 합니다.
- **불단왕 매매법 탭** — 유튜버 '불장단타왕'의 무료 강의 1~6강과 인터뷰 자막을 정리하고 주식에 적용: ① 종목 분석(일·4시간·1시간·15분·5분봉 사이클 판독, VPVR·VWMA100·이평선 차트, RSI 단계·다이버전스·트랩·권총/ㄴ자 감지, 근거 중첩 점수와 체크리스트, 손절·시간 손절·1R 포지션 크기) ② 강의 정리(코인 전용/주식 적용 표시, 용어 사전) ③ 계산기(복구·레버리지·포지션·분할 매수·하루 운영 규칙)와 감정 기록 매매일지. RSI 단계 기준값은 강의에 없어 가정값(편집 가능)입니다.
- **멀티 차트 탭 (4분할, ㅁ자 배치)** — 차트 4개를 2×2로 동시에 표시(좁은 화면은 세로로 쌓임). 칸마다 종목(회사명 검색·자동완성)·봉(1분~월)·차트 유형(캔들/하이킨아시/라인)·지표(EMA20·SMA50·SMA200·볼린저·세션 VWAP·거래량·RSI)를 따로 고르고, 휠 확대·드래그 이동·더블클릭 초기화, 크로스헤어 시각 연동, 한 칸만 크게 보기(Esc 복귀)를 지원합니다. `4종목 보기`(SPY·QQQ·IWM·DIA)와 `한 종목 4시간대`(주·일·60분·15분) 프리셋, 종목/봉 일괄 적용, 설정 자동 저장. 분봉 칸은 Worker 최신 배포가 필요합니다.

### 안드로이드(폰)에서 쓰기 — 홈 화면 앱(PWA)

`docs/` 폴더가 폰용 배포본입니다 (Tailwind·아이콘 글꼴을 미리 빌드해 넣어 빠르고, 설치 정보·서비스 워커 포함).

1. **올리기** (둘 중 하나, 본인만 쓰는 경우)
   - **Cloudflare Pages**: Workers & Pages → Create → Pages → 이 GitHub 저장소 연결, 빌드 명령 없음, **출력 디렉터리 `docs`**. (비공개 저장소도 무료)
   - **GitHub Pages**: 저장소 Settings → Pages → Branch 를 이 브랜치, 폴더 `/docs` 로 지정. (비공개 저장소는 유료 플랜 필요)
   - **Pages 메뉴가 안 보이는 경우**: Cloudflare가 Pages를 Workers로 합치는 중이라 Pages 만들기 화면이 숨겨져 있을 수 있습니다. Workers & Pages → Create → **Import a repository**(Workers Builds)로 이 저장소를 연결하세요. **Root directory를 `site`로 지정**하세요(`site/wrangler.jsonc`가 `docs/`를 정적 파일로 올리도록 설정되어 있습니다). 빌드 명령은 비우고, 배포 명령은 기본값(`npx wrangler deploy`)을 쓰면 됩니다. 시세 프록시 Worker(`pentanalyst-proxy`)에는 이 설정을 연결하지 마세요 — 프록시는 저장소 루트의 `wrangler.jsonc`로 배포됩니다(아래).
2. **폰 크롬**에서 올라간 주소(https)를 열고 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**.
3. 처음 한 번 우측 상단 **API 키 & 구글 검색 설정**에 Worker 주소(와 Gemini 키)를 입력합니다. (폰 브라우저에만 저장되며 PC와 동기화되지 않습니다.)

`index.html` 을 고친 뒤에는 `cd tools && npm install && python3 build.py` 로 `docs/` 를 다시 만들어 커밋하세요.
(`index.html` 을 직접 열어 쓰는 방식은 그대로 동작합니다.) 서비스 워커는 앱 껍데기만 저장하고 시세·검색 응답은 저장하지 않으며, 인터넷이 되면 항상 최신 화면을 받습니다.

### Worker(시세 프록시)를 GitHub 푸시로 자동 배포하기 (선택)

저장소 루트의 `wrangler.jsonc`가 `worker/index.js`를 `pentanalyst-proxy`로 배포하도록 설정되어 있습니다. Cloudflare에서 Workers & Pages → `pentanalyst-proxy` → Settings → Builds 에서 이 저장소를 **Root directory = 저장소 루트(`/`)**, 배포 명령 `npx wrangler deploy`(기본값)로 연결하면, 지정한 브랜치에 푸시할 때마다 Worker가 자동으로 새로 배포되어 대시보드에 코드를 붙여 넣을 필요가 없습니다. (연결하지 않고 대시보드에서 직접 붙여 넣는 방식도 그대로 쓸 수 있습니다.)
