# 유로잭팟 분석기

단일 파일 프론트엔드. `index.html`을 브라우저에서 바로 열면 됩니다 (서버·빌드 불필요).

- `index.html` — 앱 (통계 분석, 추천 조합, 백테스트, CSV 가져오기)
- `data.js` / `results.csv` — 2012-03-23 ~ 2026-09-29, 994회차 추첨 결과
  (출처: [dev-baris/lottery-archive](https://github.com/dev-baris/lottery-archive))

## 분석 방식
- 번호별 **장기 빈도 · 최근 N회 빈도 · 미출현 기간**을 표준점수(z)로 만들어 가중합
- 유로 번호 범위 변경(1–8 → 1–10 → 1–12)을 반영해 각 번호가 뽑힐 수 있던 회차만 기준으로 기대값 보정
- 카이제곱 검정으로 추첨의 균일성 확인, 백테스트로 전략의 실제 적중률을 무작위 기대값(0.5개)과 비교

> 유로잭팟은 독립 무작위 추첨이라 어떤 방법도 당첨 확률을 높이지 못합니다. 참고·재미용입니다.

## 데이터 갱신
앱의 **데이터** 탭에 새 회차(`date,n1,n2,n3,n4,n5,e1,e2`)를 붙여넣으면 브라우저에 저장되어 즉시 반영됩니다.
저장소 데이터를 갱신하려면 `results.csv`를 교체한 뒤:

    python3 -c "s=open('results.csv').read().strip();open('data.js','w').write('window.EJ_CSV = \`'+s+'\`;\n')"
