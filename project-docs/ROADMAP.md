## R-1 설계 메모 (앱 코드 대조 결과, 2026-10-29)
스케줄 Python 점수(`features.py score`)의 입력이 앱에 이미 있는지 대조했다.

| Python 점수 입력 | 앱에 있는가 | 위치 |
|---|---|---|
| 200일선 이격 / 50일선 이격 / 20일선 이격 | 있음 | `taSignalsLite` stats `sma200Diff`/`sma50Diff`/`sma20Diff`, 스크리너 `sma200Pct`/`sma50Pct`/`sma20Pct` |
| RSI14 | 있음 | stats `rsi14`, 스크리너 `rsi` |
| 3개월 수익률 | 있음 | 스크리너 `perf3m` (signals stats에는 없음) |
| ATR | 있음 | stats `atrPct`, 위험 계산기의 ATR 손절(2×ATR) |
| PER / PEG / 컨센서스 | 있음 | 스크리너 `pe`/`fpe`/`peg`/`recMean`/`targetUpside` (Worker fundamentals·deep) |
| 지지선 / 매수가 / 손절 / 목표 (SMA20·50·200, 20·60일 저점 기준) | **없음** (규칙 형태로는) | 앱은 ATR 손절 프리셋만 있음 → 신규 구현 필요 |
| 실적 발표일 | 불명 | Worker `calendar` 라우트가 대체 가능한지 확인 필요 (KNOWN_GAPS) |
| 눌림목 판정 | 정의가 다름 | 앱 `pullback` 칩은 EMA20±1ATR·RSI 40~55, Python은 지지선 거리 ≤4%. 하나로 정해야 함 |

결론: 점수 입력은 대부분 앱에 있다. 새로 만들 것은 (1) 지지/매수/손절/목표 계산, (2) 점수·verdict 규칙 함수, (3) 이를 담은 브릿지 필드, (4) 눌림목 정의 통일이다. 규칙 함수는 `// @@PURE-START/END` 같은 순수 함수 구간에 두면 테스트하기 쉽다(앱의 `scoreOf` 주변 관례).

## 알려진 규칙 약점 (독립 리뷰 + 이식 중 발견, 고치지 않음 — R-6 측정 뒤 결정)
1. 점수 중복: 200일선·50일선·3개월 수익률이 모두 추세를 재서 상승 추세 종목은 한꺼번에 +4를 받는다 → 5점 기준이 사실상 '모멘텀 상위' 필터. 눌림 가점(+2)과 50일선 이탈(−1)은 같이 나타나기 쉽다.
2. 하락 추세 = 자동 sell: 200일선 아래(−2)만으로 sell. '매도'가 아니라 '매수 금지(avoid)'로 라벨을 나누고 보유 여부로 구분할지 검토 (R-2와 함께).
3. 컨센서스 UNDERPERFORM 무점수, 가중치 ±1로 약함.
4. SMA200 지지선이 일봉 길이에 의존: 130봉이면 200일선 지지가 빠진다 → 연결 시 전체 일봉을 넘기고 `hasSma200` 확인.
5. 목표가 +15% 상한·PER 45/PEG 1.5 기준은 변동성·업종 구분이 없다.
6. 'buy' 조건(지지선 4% 이내)은 지지가 20일 저점이면 거의 항상 충족.
7. 연결 시 위험: 단위·형 불일치('5' 문자열은 결측 취급), 조용한 열화(결측 → hold), 앱·Claude 두 곳 계산 불일치(`cfgVersion`을 브릿지에 기록하고 버전 비교).

## 설계 근거 메모 (2026-10-29 조사, 모두 2차 요약이라 원문 확인 필요)
- 이동평균 이격: 21일/200일 이동평균 비율이 높은 종목이 이후 수익이 높았다는 연구(Avramov·Kaplanski·Subrahmanyam, 1977~2018 미국 주식, 장기 이평선 위 종목 우위). 현재 규칙의 '200일선 위 +2 / 아래 −2'와 방향이 같다. 반면 '눌림목 매수'(20일선 −4%)가 초과수익을 낸다는 근거는 이번 조사에서 확인하지 못했다 → 눌림목 가점(+2)은 측정 우선 항목.
- 손절: ATR 배수 방식은 변동성에 맞춰진다는 장점이 설명되지만, 조사한 글들은 백테스트 근거 없이 2~3배를 권한다(상업 제품 홍보 포함). 현재 '지지 − 1.5×ATR'은 임의값 → 앱의 위험 계산기(2×ATR)와의 통일 및 측정 필요.
- 실적: 발표 후 수 주간 이어지는 드리프트(PEAD)와 발표 전후 변동성 확대가 알려져 있어 '실적 직전 신규 진입 보류'는 위험관리로 타당하나, 3일이라는 창은 임의값이다.
- 점수 가중: 최적화한 가중치는 과적합 위험이 크다는 일반 논의가 있다. 현재 규칙은 정수 가점제(사실상 동일 가중)라 단순하지만, 항목끼리 상관이 높아(200일선·50일선·3개월 수익률) 추세를 중복 가산한다.
