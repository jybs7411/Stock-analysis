# 프로젝트 문서 (PentAnalyst × 주식 데스크)

두 앱을 함께 발전시키기 위한 **공용 컨텍스트**입니다. 새 세션은 이 파일(요약)부터 읽고, 필요한 문서만 더 엽니다.

## 한 장 요약 (2026-10-29 기준)
- **PentAnalyst**(이 저장소, `index.html` + Cloudflare Worker): 데이터 수집·계산·표시·저장. 결정론적이고 항상 켜져 있음.
- **주식 데스크**(Claude 아티팩트): Claude만 할 수 있는 일 — 웹 리서치, 비정형 정보 해석, 서술형 종합 판단, 차트 이미지 해석.
- **브릿지**(Google Drive 폴더 `주식데스크-브릿지`): 앱 → 데스크는 시세·일봉 파일, 데스크 → 앱은 분석 파일.
- 판별 기준: **"코드로 짤 수 있으면 앱의 일, 없으면 데스크의 일."**
- 현재 최대 이슈: 점수·판정 로직이 3벌(앱 `scoreOf` / 데스크 분석 탭 / 스케줄 Python)이고, 규칙 점수가 "Claude 판정"으로 표시됨.

## 운영 규칙
1. 작업을 마칠 때 **ARCHITECTURE / DECISIONS / ROADMAP** 중 바뀐 것을 같은 커밋에서 갱신한다.
2. 줄 번호를 적지 않는다. 함수·모듈(`<script id=...>`) 이름으로만 가리킨다.
3. 문서와 코드가 어긋나면 **코드가 맞다.** 어긋남을 발견하면 문서를 고치고 DECISIONS에 남긴다.
4. 이 폴더는 이 저장소가 원본이다. 데스크 아티팩트와 claude.ai 프로젝트에는 사본을 두지 말고 "원칙 요약 + 이 폴더 위치"만 적는다.
5. 데스크(아티팩트) 쪽 사실은 아티팩트에서 직접 확인한 것만 적는다. 확인 못 한 것은 KNOWN_GAPS로.
